## ✨ Особенности проекта

- **Адаптивный дизайн** — идеально смотрится как на огромных мониторах, так и на экранах смартфонов.
- **Анимация загрузки** — стильный прелоадер с процентами и эффектом «компиляции».
- **Плавное появление** — карточки платформ появляются каскадом при загрузке страницы.
- **Интерактивность** — приятные hover-эффекты: подсветка, изменение цвета иконок и сдвиг стрелок.
- **Чистый код** — проект разделён на директории, не используется тяжеловесных фреймворков (только Vanilla JS и CSS).
